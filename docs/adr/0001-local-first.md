# ADR 0001 — Local primeiro, independente

Status: adotada na V0.1, 26/11/2026.

O escopo exige ausência de base centralizada e independência da Jornada de Bia. Escolhemos HTML/CSS/ES modules, IndexedDB e motores puros no dispositivo. FastAPI serve somente conteúdo genérico. Sem contas, cookies, sincronização ou banco de crianças. Limites: perfis compartilhados expõem registros; dispositivo pode apagar armazenamento. Interface deve informar isso e permitir exclusão e exportação.
