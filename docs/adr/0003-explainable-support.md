# ADR 0003 — Evidência limitada e apoio sempre disponível

Status: adotada experimentalmente, 26/11/2026.

Regras puras distinguem modelo/pistas e conclusão sem pistas, com incerteza explícita. Sem velocidade, abandono ou fala como indicadores. Duas sessões distintas são padrão configurável, não marco de domínio. Sugestões são opcionais e o vocabulário não é bloqueado. Grafo ordena relações e anotações editoriais, sem presumir adequação individual. Revisão pedagógica é necessária para ampliar o método.
